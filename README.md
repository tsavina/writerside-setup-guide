# Writerside Setup Guide

**[Read the guide online →](https://tsavina.github.io/writerside-setup-guide/)**

A short tutorial that walks you through setting up a Writerside documentation project: from installing 
the plugin in IntelliJ IDEA to publishing the sources on GitHub.

## About this guide

The guide covers:

- Installing the Writerside plugin
- Creating a new documentation project
- Adding a topic in semantic XML
- Building the project locally
- Pushing the sources to GitHub

## Project structure

| Path | Description |
| --- | --- |
| `Writerside/topics/Setting-Up-a-Writerside-Documentation-Project.topic` | The guide's source file in semantic XML |
| `Writerside/images/` | Annotated screenshots used in the guide |
| `Writerside/hi.tree` | Table of contents for the help instance |
| `Writerside/writerside.cfg` | Writerside module configuration |

## View the guide

The easiest way is the [live version on GitHub Pages](https://tsavina.github.io/writerside-setup-guide/).

To read the source files instead:

1. Clone this repository.
2. Open it in IntelliJ IDEA with the [Writerside plugin](https://plugins.jetbrains.com/plugin/20158-writerside) installed.
3. Open `Writerside/topics/Setting-Up-a-Writerside-Documentation-Project.topic`.
4. Use the Writerside preview pane to read the rendered version, or build the project locally via **Export To → Web Archive**.
